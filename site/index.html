step 01Peeling the stack

Your infra used to be four products and a duct-taped day of glue. Scroll — each layer peels off the box and lands on the left, stamped with the gate that proves it.

  1. layer 1 / telemetry

    Sentry

    Capture every ingest frame — POST /api/{project}/envelope/ is wire-compatible with Sentry, and OTLP rides the same writer. Your instrumented SDKs don't notice the swap.

    • PII scrubbed at capture (JSON key redaction)
    • errors + crashes survive every watermark at 100%
    • provenance: gate P1·P4 · soak 20/20 (v1.1.2c)
  2. layer 2 / durable jobs

    Temporal + Redis

    Webhooks durably enqueued in 202 ms, delivered with leases, retries, a reaper, an idempotency sweep and honest DLQ accounting — one fsync'd segment file owning the state.

    • zero-lost gate: 5,000 / 5,000 delivered · DLQ 0
    • connection held while your app restarts
    • provenance: gates P3 · phase C of the demo above
  3. layer 3 / edge + TLS

    NGINX

    Reverse proxy, WAF scanner face, rate limiter, rustls TLS with hot reload. Scanner paths (/.env, /.git/*, wp-admin, traversals) die before the limiter or the writer ever see them.

    • ≥ 8,000 req/s throughput gate
    • 429s authored by the limiter, logged per rule
    • provenance: gates P7 shield · P2 throughput
  4. layer 4 / LLM spend

    The egress cache

    Point your app's OPENAI_BASE_URL at it. Singleflight collapses a burst of identical calls to one upstream call; the response cache + SimHash near-cache catch the near-duplicates; a ledger prices every token per tenant → provider → model.

    • demo replay above: 24 calls → 1 upstream · 95.8% saved
    • 1,001-variant storm caught at Hamming ≤ 3
    • provenance: gates P4 singleflight + SimHash · finops ledger

step 02The Torture Room

"Break the box. No one has succeeded." Four documented ways people attempt it — each already answered by a gate. The interactive room opens in the next pass; the evidence is already here.

kill -9 mid-append

A real SIGKILL during frame writes. RAW segments tolerate the torn tail; the node resurrects itself with its audit chain intact.

0.203 s recovery · 0 records lost gate P5 resurrection · v1.1.2c soak

flip bytes in a sealed segment

Corrupt a cold .zst. The read path fails verification, surfaces Err(Corrupt), and restores the digest-verified replica from the cold tier.

self-healed — visible in the demo replay, phase E gate P6 bit-rot heal

flood 5,000 duplicate webhooks

Real Stripe retries share event IDs. The dedup lane swallows the repeats while every distinct event still delivers.

5,000 / 5,000 delivered · DLQ 0 gate P3 zero-lost

squeeze the RSS watermark

Push the node past Shed85. Head-sampling drops *healthy* records first; errors, crashes and queue jobs keep flowing at 100%.

errors stay 100% even at Backpressure95 gate P4 RAM shed
